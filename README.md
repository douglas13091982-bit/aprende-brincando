# 🦉 AprendeBrincando

Jogo educativo completo de **Matemática** e **Português** feito para crianças, em formato **PWA instalável** no celular.

## ▶️ Jogar agora

Abra o site (depois de ativar GitHub Pages):

**https://douglas13091982-bit.github.io/aprende-brincando/**

## Como instalar no celular

### Android (Chrome)
1. Abra o site
2. Toque no banner **"Instalar"** ou menu ⋮ → "Instalar aplicativo"

### iPhone (Safari)
1. Abra o site no Safari
2. Toque em Compartilhar → **"Adicionar à Tela de Início"**

## Recursos

- Matemática: soma, subtração, multiplicação e divisão (3 níveis)
- Português: completar palavras, sílabas e ortografia (3 níveis)
- Funciona offline
- Confetes e estrelas ⭐
- Design moderno e alegre

## Como publicar (GitHub Pages)

1. Vá em **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder `/ (root)`
4. Save

Pronto! Em alguns minutos o site estará no ar.
